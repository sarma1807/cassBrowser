# cassBrowser
Smart GUI for browsing data in Apache Cassandra clusters

#### cassBrowser has been natively compiled as a single portable executable binary file, can run on RedHat compatible Linux systems, Ubuntu, Apple Mac and Windows. ( available under Releases )
